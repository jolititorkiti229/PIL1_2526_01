3. Conception du projet

Architecture logicielle

L'application suit une architecture client-serveur MVC (Modèle-Vue-Contrôleur) :

Navigateur
(HTML/CSS/JS)
⟷
Flask
(Routes/Vues)
⟷

Le client envoie des requêtes HTTP → Flask traite et interroge MySQL → réponse HTML rendue via Jinja2.

5. Algorithme de matching

Le score de compatibilité entre deux utilisateurs est calculé sur 100 points répartis en 3 critères :

📐 Formule de scoring

  • Compétences (50 pts max) : intersection des lacunes de l'utilisateur avec les forces du mentor, divisée par le nombre de lacunes.
  • Disponibilités (30 pts max) : nombre de jours en commun × 10, plafonné à 30.
  • Filière (20 pts) : même filière = 20 pts, filière différente = 10 pts.
score = (|lacunes_user ∩ forces_mentor| / |lacunes_user|) × 50
      + min(|jours_communs| × 10, 30)
      + (20 si même filière, sinon 10)

Ce score est calculé à la volée lors des recherches et des suggestions du tableau de bord. Il est également stockable dans la table matching pour l'optimisation des performances.

  • Python 3.10 ou supérieur
  • MySQL 8.0 ou supérieur
  • pip (gestionnaire de paquets Python)

1

git clone https://github.com/[org]/PIL1_2526_[XX].git
cd PIL1_2526_[XX]
2

Créer et activer un environnement virtuel

python -m venv venv
# Windows :
venv\Scripts\activate
# Linux/Mac :
source venv/bin/activate
3

Installer les dépendances

pip install -r backend/requirements.txt
4

Configurer la base de données

# Importer le schéma SQL dans MySQL :
mysql -u root -p -e "CREATE DATABASE mentorlink CHARACTER SET utf8mb4;"

Configurer les variables d'environnement

cp backend/.env.example backend/.env
# Éditez backend/.env avec vos identifiants MySQL
6

Lancer l'application

cd backend
python app.py
# L'application est accessible sur http://127.0.0.1:5000

7. Manuel d'utilisation

🔐 Créer un compte

  1. Accédez à la page d'accueil et cliquez sur S'inscrire.
  2. Remplissez votre nom, prénom, email, téléphone, filière et niveau.
  3. Sélectionnez vos points forts (matières que vous maîtrisez) et vos points faibles (matières où vous avez besoin d'aide).
  4. Cliquez sur S'inscrire. Vous êtes automatiquement connecté.

👤 Compléter son profil

  1. Allez dans Mon profil depuis la barre latérale.
  2. Modifiez vos informations personnelles et votre bio.
  3. Ajoutez vos disponibilités horaires (jour + créneau).
  4. Cliquez sur Enregistrer les modifications.

🔍 Rechercher un mentor

  1. Cliquez sur Rechercher dans la barre latérale.
  2. Filtrez par matière, filière, niveau ou disponibilité.
  3. Cliquez sur Voir profil pour consulter un mentor.
  4. Cliquez sur Contacter pour ouvrir une conversation ou Demander mentorat pour envoyer une demande.

📋 Publier une offre ou une demande

  1. Allez dans Mes offres / demandes.
  2. Cliquez sur + Créer une nouvelle offre.
  3. Choisissez le type (offre ou demande), la matière, le format et une description.
  4. Cliquez sur Publier.

💬 Utiliser la messagerie

  1. Accédez à Messagerie depuis la barre latérale.
  2. Sélectionnez une conversation dans la liste de gauche.
  3. Tapez votre message dans le champ en bas et cliquez sur le bouton d'envoi.
  4. Les messages non lus sont signalés par un badge rouge.
⚠️ Pour recevoir des notifications en temps réel, assurez-vous que le serveur Flask est en cours d'exécution et rechargez la page régulièrement (la messagerie temps réel nécessite WebSockets, non implémentés dans cette version de base).
