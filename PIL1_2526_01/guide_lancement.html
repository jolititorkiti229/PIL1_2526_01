Instructions complètes pour installer et lancer le projet en local

01

Prérequis

Logiciels à installer avant de commencer

Logiciel Version Téléchargement Statut
Python 3.10+ python.org/downloads Requis
Git 2.x git-scm.com Requis
MySQL 8.0+ dev.mysql.com Optionnel (local)
VS Code Dernière code.visualstudio.com Recommandé
02

Cloner le dépôt GitHub

Récupérer le code source du projet

1

Ouvrez un terminal

Sur Windows : cmd ou PowerShell. Naviguez où vous voulez placer le projet.

2

Clonez le repo

git clone https://github.com/jolititorkiti229/PIL1_2526_01
cd PIL1_2526_01/backend
03

Créer l'environnement virtuel

Isoler les dépendances du projet

1

Créer l'environnement

python -m venv venv
2

Activer l'environnement

Sur Windows :

venv\Scripts\activate

Sur Mac/Linux :

source venv/bin/activate
3

Installer les dépendances

pip install -r requirements.txt

Si le fichier n'existe pas, installez manuellement :

pip install flask mysql-connector-python python-dotenv
04

Configurer le fichier .env

Variables de connexion à la base de données Railway

⚠️
Créez ce fichier manuellement dans le dossier backend/. Ne le commitez jamais sur GitHub — il contient des informations sensibles.

Créez un fichier nommé .env avec ce contenu :

# Clé secrète Flask
SECRET_KEY=mentorlink_secret_key_ifri_2026

# Base de données Railway
MYSQL_HOST=acela.proxy.rlwy.net
MYSQL_USER=root
MYSQL_PASSWORD=[mot_de_passe_fourni_par_le_groupe]
MYSQL_DB=railway
MYSQL_PORT=17487
05

Lancer l'application

Démarrer le serveur Flask en local

1

Assurez-vous d'être dans le bon dossier

cd PIL1_2526_01/backend
2

Lancez Flask

python app.py
3

Ouvrez l'application dans le navigateur

Vous devriez voir ce message dans le terminal :

* Running on http://127.0.0.1:5000
* Debug mode: on

Allez sur http://127.0.0.1:5000 dans votre navigateur.

✅
Si la page d'accueil s'affiche, l'installation est réussie ! La base de données est partagée sur Railway, vos données sont synchronisées avec tous les membres du groupe.
06

Erreurs courantes

Solutions aux problèmes fréquents

!

ModuleNotFoundError: No module named 'flask'

Les dépendances ne sont pas installées. Exécutez :

pip install -r requirements.txt
!

Can't connect to MySQL server

Le fichier .env est absent ou mal configuré. Vérifiez que le fichier existe dans backend/ et que le port est bien 17487.

!

Lost connection to MySQL server

La connexion Railway a expiré. Relancez simplement python app.py.

!

Address already in use (port 5000)

Un autre processus utilise le port. Fermez-le ou changez le port :

python app.py --port 5001
